### Method and auditable numeric inputs

1. Use the [Datacurve v1.1 JSON](https://deepswe.datacurve.ai/artifacts/v1.1/leaderboard-live.json) `mean_output_tokens` and `mean_cost_usd` for **mini-swe-agent**, explicitly scoped to scored rollout attempts. Its cost `cost_basis` is absent for all five reference rows below. For each predecessor, pair that measured DeepSWE mean with [Artificial Analysis](https://artificialanalysis.ai/models/muse-spark-1-3) **total output tokens generated by the whole Intelligence Index evaluation**, rounded to millions, and its **weighted USD per Intelligence Index task**, rounded to cents, for that *same predecessor variant*. The II totals are **not output tokens per task**. The ratio assumes the II evaluated a comparable task mix/count across model pages; neither II token totals nor II dollars are DeepSWE-specific.
2. For each provider separately, compute `r_output_i = Datacurve_output_i / AA_II_total_output_M_i` (units: DeepSWE output tokens per attempt **per million AA II aggregate output tokens**) and `r_cost_i = Datacurve_cost_i / AA_II_cost_per_task_i` (cross-benchmark unit transfer). Multiply each predecessor's ratio by the *target's own same-effort AA II figure*, then take the **unweighted arithmetic mean of the two projections**. The minimum and maximum projections expose the sensitivity to choosing a predecessor; they do not quantify future uncertainty. No cost-to-token inversion, score regression, mixed-token-to-output conversion, or fabricated per-task denominator is used.
3. **Meta:** Datacurve Muse Spark 1.1 **xhigh** (452 attempts): **74,008.420354 output**, **$2.361142644**; AA II **170M aggregate output**, **$1.38/task**. Muse Spark 1.2 **xhigh** (452): **99,226.380531**, **$3.695504818**; AA II **130M**, **$0.97/task**. Target AA Muse Spark **1.3 max**: **170M**, **$1.60/task**. Token pair projections: 74,008.420354 and 129,757.574541 → **101,882.997447**. Cost pair projections: $2.737556689 and $6.095678050 → **$4.416617370**. [AA's separate Muse Code 1.3 max variant](https://artificialanalysis.ai/agents/coding-agents/comparisons/grok-build-vs-muse-code) reports **122,491.69026548673 DeepSWE output tokens per AA task attempt** on that different harness, plus **$3.98/task** and **16.7M mixed tokens/task** averaged over the three-benchmark Coding Agent suite. Its $3.98 is an **alternative exact-variant suite-cost proxy**, *not* a DeepSWE-only cost or a second independent observation. Neither the AA DeepSWE output mean nor the suite figures measure Meta's mini-swe-agent run; the 16.7M mixed-token figure cannot determine its output tokens. Meta describes ~25% fewer **total tokens** on its own engineer coding comparisons against 1.2; those are not an output-token DeepSWE ratio, so we do not apply 0.75. The xhigh→max transfer and disagreement between predecessor ratios make this especially speculative.
4. **xAI:** Datacurve Grok **4.5 high** (452): **35,525.331858 output**, **$2.415748173**; AA II **77M aggregate output**, **$1.04/task**. Grok **4.6 high** (451): **61,160.944568**, **$4.384873224**; AA II **94M**, **$1.86/task**. Target AA Grok **4.7 high**: **200M**, **$2.73/task**. Output projections: 92,273.589243 and 130,129.669293 → **111,201.629268**. Cost projections: $6.341338953 and $6.435862313 → **$6.388600633**. The [AA Grok 4.7 article](https://artificialanalysis.ai/articles/benchmarking-grok-4-7) instead gives **~81k output per II task for 4.7 xhigh** and [Grok Build](https://artificialanalysis.ai/agents/coding-agents/comparisons/grok-build-vs-muse-code) gives **$8.82 and 14.3M mixed tokens per Coding Agent suite task for 4.7 xhigh**: these are **xhigh, not the developer high target**. Neither is substituted as high usage or output. The xAI release's $2/$6 per million input/output tokens is a *rate card*, not task usage.
5. **Google:** [Google's evaluation PDF](https://storage.googleapis.com/deepmind-media/gemini/gemini_3-8_flash_model_evaluation.pdf), p.2 and p.4, identifies **`gemini-3.8-flash`, high thinking, mini-SWE-agent, DeepSWE v1.1**. Datacurve `mini_swe_agent_gemini_3_8_flash_high` (447 attempts, four runs) directly gives **$2.362349413758389** and **143,242.6644295302 output**. Same API model label and effort, *not proven identical checkpoint, attempt sets, or source cost snapshot*. This is a cross-run estimate for the Google row, not a recomputation from [AA's ~48k high-effort output tokens per unrelated Intelligence Index task](https://artificialanalysis.ai/articles/gemini-3-8-flash). AA's $0.58/task is likewise a different benchmark. The Fireworks $2.362/task matches Datacurve after rounding, but unknown version and accounting prohibit counting it as validation.

**Calibration diagnostic:** holding out each predecessor in turn, the two-point output-transfer absolute percentage errors are Meta **75.3% / 43.0%** (MAPE **59.1%**) and Grok **41.0% / 29.1%** (MAPE **35.1%**); cost errors are Meta **122.7% / 55.1%** (MAPE **88.9%**) and Grok **1.49% / 1.47%** (MAPE **1.48%**). Each calculation has only **two model versions**, rounded II inputs, unrelated II and DeepSWE workloads, and potentially different price snapshots. The apparently tight Grok cost envelope does **not** imply high precision for a new version. Do not use Meta or Grok figures as a point estimate of a bill.
