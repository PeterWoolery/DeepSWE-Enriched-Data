# Source registry

The structured registry is [`data/sources/registry.json`](../data/sources/registry.json); the application renders it at the Sources view. It distinguishes publisher/source category, document status, captured response hash/date, and access/reuse notes. A source-review label does not imply independent replication.

## Effort-order references

The reviewed map cites the current [OpenAI reasoning effort guide](https://platform.openai.com/docs/guides/reasoning), [Anthropic effort documentation](https://docs.anthropic.com/en/docs/build-with-claude/effort), [xAI reasoning API](https://docs.x.ai/developers/model-capabilities/text/reasoning), and [Google Gemini thinking levels](https://ai.google.dev/gemini-api/docs/thinking?hl=en). They document provider-specific intensity semantics/available values. They do not establish cross-provider compute equivalence. The map is per exact feed model string; unmapped labels are not connected.
